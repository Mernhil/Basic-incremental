# Style references (the user's learning set)

The user's current pixel-art learning set (2026-11-09), replacing the earlier catalogue picks. Study the shading, outline, material, ornament and silhouette feel and draw something new in that spirit; never copy a picture. Everything here was marked Keep and Learn by the user and called perfect.

- `C:/Basic Incremental/design/references/itch/learn/elie-<character>.png` (local, untracked: the pack licences forbid redistribution, so these 34 files are not in the repository; 34 files, **listed first: Keep + Learn, the strongest references**, user 2026-11-11: "that's how perfect generation looks"): the front (south) idle still of every Elie Studio character ("elie automata") from the user's picked packs, cut by `scripts/art/cut-learn.py`. Learn: chibi proportions, about 125 px tall on a 256 canvas (the small packs about 60 px), at most 64 colours, a dark outline, a strong silhouette for each character, and gold or bright trim on dark armour. Characters: abyssal-voidcaller, apprentice-alchemist, animated_stone_golem, ivoryhood_drowned_relic_warden, plague_lantern_keeper, blood-duchess, bone-inquisitor, cathedral-reliquary, crimson-seraph-priestess, crimson-wolf, abyssal_anchor_leviathan, abyssal_sharkfang_raider, drowned_leviathanbeard_high_admiral, dwarven-hammer-engineer, faceless-void-reaper, fire-witch, glacierbreaker-knight, golden-cross-novice-priestess, gothic-bloodhunter, gothic-corsair, holy-judiciar, hooded-rogue-assassin, ice-sorceress, ivory-direwolf, ivory-sun-priestess, plague-doctor, royal-archon, royal-knight, sanctuary-archangel, shield-knight, siege-construct, skeleton-crossbow-ranger, wasteland-juggernaut, woodland-stalker-wolf.
- `6f.png` and `6g.png`: the two legacy maul pictures that set the direction (separate chunky crystal prisms with flat colour set in solid bodies, simple palettes; 6f mint and lilac crystal on teal with gold trim, 6g black with purple cracked crystals and gold).
- `h-<type>-m<0-3>.png` and `h-<type>-v<0-3>.png`: the 88 Heirloom candidates (11 item types, a Mythic-side and a Void-side Heirloom each, four candidates per side). They show the target for the best items in the game: each its own colour identity, ornate, large and clearly above any ordinary tier, still a clean pixel picture with a bold dark outline.
